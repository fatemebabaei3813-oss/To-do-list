# Todo-list

A simple and functional To-Do List web application built as a Front-End practice project.

The project allows users to manage their daily tasks and also fetches additional tasks from an external API.

✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📊 Display the number of pending tasks
- 🌐 Fetch tasks from an external API
- 📱 Clean and responsive user interface
- 🎨 Simple and user-friendly design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
